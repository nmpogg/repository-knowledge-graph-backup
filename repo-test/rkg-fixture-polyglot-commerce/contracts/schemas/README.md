# Vendored validation schemas
- `openapi-3.0.json`: https://spec.openapis.org/oas/3.0/schema/2024-10-18 — OpenAPI Initiative, Apache-2.0.
- `asyncapi-2.6.json`: https://github.com/asyncapi/spec-json-schemas/blob/master/schemas/2.6.0.json — AsyncAPI Initiative, Apache-2.0.

`SHA256SUMS` pins the exact downloaded bytes. These are validation inputs, not generated client/server code. The official AsyncAPI schema alone does not express every specification constraint; the root README describes the additional checks and this fixture's deliberate scope.
