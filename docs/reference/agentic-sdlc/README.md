# Agentic SDLC reference documents

Các tài liệu trong thư mục này chỉ dùng để tham khảo và không phải nguồn chuẩn
tắc của Repository Knowledge Graph.

- `agentic-sdlc-workflow-reference.md`: quy trình Agentic SDLC tổng quát.
- `PRD_template.md`: template tham khảo khi soạn PRD.

Khi nội dung tại đây khác với `AGENTS.md` hoặc artifact chuẩn tắc trong `.aide/`,
`AGENTS.md` và `.aide/` được ưu tiên.
